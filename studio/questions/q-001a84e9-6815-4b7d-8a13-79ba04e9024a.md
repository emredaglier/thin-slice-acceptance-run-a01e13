The edits themselves are what ticket 01 asks for, but the file list comes from `$TMPDIR/files.txt`, which is outside the project and can't be read, so nobody can check which files `sed -i` would rewrite. Run it again with the list built inside the repo, from tracked files only, so it can be checked. For example: `git grep -lz -e '@house/' -e 'house:motion-fault' | xargs -0 sed -i '' -e 's#@house/#@kiln-and-clay/#g' -e 's#house:motion-fault#kiln-and-clay:motion-fault#g'`. Make the `infra/project.env` edit as a separate command. Then check with `git grep '@house/'`, which should find nothing, and run lint, typecheck and test.
