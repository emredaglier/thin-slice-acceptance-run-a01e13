Denied. `cd ../..` puts you at the project root, which is the main checkout and not your worktree. Lint there would check the wrong tree and prove nothing about 03-look. Run the checks from the root of your own worktree instead: `pnpm -w lint` from inside `packages/ui` does it, or run `pnpm lint` after `cd` to your worktree's absolute root path. Then run `pnpm typecheck`, `pnpm test` and `pnpm check:assets` there too, and report each result.
